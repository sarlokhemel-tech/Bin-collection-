# ESP32 WiFi Repeater (ESP-IDF + NAT)

## বানানোর নিয়ম
1. এই ফোল্ডারের সব ফাইল GitHub repo-তে push করুন (branch: main)।
2. Actions ট্যাবে "Build ESP32 Repeater" চলবে। শেষে Artifacts থেকে `esp32-repeater-bin` নামান।
   - `merged-binary.bin` → প্রথমবার ফ্ল্যাশ, অফসেট **0x0**
   - `esp32_repeater.bin` → পরে OTA আপডেটের জন্য (প্যানেল → সিস্টেম → OTA)
3. ফ্ল্যাশের পর `ESP32-Repeater` (পাসওয়ার্ড `12345678`) হটস্পটে কানেক্ট করে ব্রাউজারে `192.168.4.1` খুলুন।
   ইউজার `admin`, পাসওয়ার্ড `admin` (প্রথমেই বদলে নিন)।

## LED সিগন্যাল (ডিফল্ট GPIO2)
| অবস্থা | আলো |
|---|---|
| রাউটার সেট নেই (শুধু হটস্পট) | ধীরে ধীরে ব্লিংক |
| রাউটারে কানেক্ট হচ্ছে | দ্রুত ব্লিংক |
| রাউটারে কানেক্টেড | স্থির জ্বলবে |
| স্ক্যান চলছে | ডাবল ব্লিংক |
| ৫+ বার কানেক্ট ব্যর্থ | ৩ ফ্ল্যাশ + বিরতি |
| ফোন হটস্পটে জয়েন করলে | ২ সেকেন্ড ৪টা দ্রুত ফ্ল্যাশ |
| OTA / রিসেট | খুব দ্রুত |

## ফ্যাক্টরি রিসেট
চালু অবস্থায় BOOT বাটন ৫ সেকেন্ড ধরে রাখুন।

## বোর্ড: ESP32 DevKit V1
- নীল LED = GPIO2 (ডিফল্ট), BOOT = GPIO0। ফ্ল্যাশের সময় সংযোগ না হলে BOOT চেপে ধরুন।

## নোট
- ৪MB ফ্ল্যাশ ধরা আছে (partitions.csv, sdkconfig.defaults)।
- রাউটার চ্যানেল ও হটস্পট চ্যানেল একই হতে হয় (একটাই রেডিও), তাই চ্যানেল অটো।
- "No internet" এড়াতে: DNS বুট থেকেই ফোনকে দেওয়া হয়, NAT বুট থেকে চালু, IP রেঞ্জ মিলে গেলে হটস্পট অটো সরে যায়, ইন্টারনেট ওয়াচডগ প্রতি ১৫ সেকেন্ডে চেক করে আর দরকারে রাউটারে রিকানেক্ট/রিবুট করে। রাউটার আছে কিন্তু ইন্টারনেট নেই হলে LED "বেশির ভাগ সময় জ্বলে, ছোট বিরতি" দেয়।
- ব্লক MAC দিয়ে হয়; ফোনের "Private/Random MAC" চালু থাকলে নতুন MAC নিয়ে ঢুকতে পারে।
