# NanoLab

Nano object detection / image classification / text classification মডেল ইম্পোর্ট ও টেস্ট, Gemini + Groq চ্যাট, এবং Accessibility Tree ক্যাপচার।

APK বানাতে: রিপো GitHub এ push করলেই Actions চলবে (`.github/workflows/build-apk.yml`)।
APK পাবেন: Actions → সর্বশেষ run → Artifacts (NanoLab-apk), অথবা Releases পেজে সরাসরি `NanoLab.apk`।
