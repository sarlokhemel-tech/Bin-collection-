রাউটারে কানেক্টেড ডিভাইস

ARP স্ক্যান করে IP ও MAC বের করে। ডিভাইসের নাম রাউটার দেয় না, তাই নিজে নাম দিয়ে রাখতে পারবেন।

রাউটার সাইড IP

DNS সিস্টেম ট্যাবের "কাস্টম DNS" থেকে আসে।

হটস্পট IP ও DHCP

রাউটারের IP রেঞ্জ (যেমন 192.168.4.x) আর হটস্পটের রেঞ্জ এক হলে ইন্টারনেট চলবে না — হটস্পট IP আলাদা রাখুন, যেমন 192.168.50.1।

MAC অ্যাড্রেস পরিবর্তন

খালি রাখলে ডিফল্ট MAC থাকবে। সেভ করলে ডিভাইস রিস্টার্ট হবে। ফরম্যাট: aa:bb:cc:dd:ee:ff (প্রথম বাইট জোড় হতে হবে, যেমন 02, 0a, 12)
